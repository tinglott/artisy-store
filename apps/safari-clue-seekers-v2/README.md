# Safari Clue Seekers — V2

A self-contained, offline browser game for family learning. It has no account, network requests, analytics, ads, or user-data collection. Scores are stored only in the browser's local storage and can be cleared from the app.

## Run
Open `index.html` in a modern desktop or mobile browser. For local development, serve the folder using any static web server.
