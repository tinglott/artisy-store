Safety boundary

Source manuscripts, credentials, and unfinished audio are never placed in this public site or repository.

Provider failover

Kokoro · local primary→Edge TTS · tested fallback→Piper · optional local fallback

Each chunk is retried, decoded, measured, hashed, and committed to a manifest before the next chunk begins. A failed run resumes at the last verified checkpoint.

Important: this Netlify site is the control and documentation layer. Long-running audio rendering belongs on protected compute, not a short-lived serverless request.
