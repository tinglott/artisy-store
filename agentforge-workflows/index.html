📡 Communication Protocol (A2A + MCP)

Request Format (JSON):
{
  "request_id": "req_12345",
  "from_agent": "lead_nurture",
  "to_agent": "data_analyzer",
  "action": "get_trending_topics",
  "params": {"time_period": "last_7_days"},
  "priority": "normal",
  "timestamp": "2026-06-29T10:45:00Z"
}
Response Format (JSON):
{
  "response_id": "resp_12345",
  "from_agent": "data_analyzer",
  "status": "success",
  "data": {
    "trending_topics": [
      {"topic": "anxiety_management", "score": 487}
    ]
  },
  "timestamp": "2026-06-29T10:45:15Z"
}
