# 💖 Mom's Day - Parent Wellness & Self-Care App

**A moment for YOU, every day.**

## What It Does

Mom's Day is a fully functional self-care and wellness app designed for parents who need to remember to take care of themselves. It includes:

✅ **Daily Dashboard** - Quick wins tracker, affirmations, wellness stats
✅ **Self-Care Ideas** - 8 quick activities (coffee break, shower, walk, dance, read, skincare, stretch, chocolate moment)
✅ **Affirmations for Moms** - 10 daily affirmations to combat mom guilt and burnout
✅ **Quick Wins Tracker** - Log everything you accomplish (big or small)
✅ **Mindfulness Sessions** - Guided 2-5 min practices (breathing, loving-kindness, body scans, anxiety relief)
✅ **Personal Timer** - Track meditation/mindfulness sessions

## Features Built In

- **100% Local Storage** - All data stays on your device
- **No Judgment Zone** - Your wins are valid, no matter how small
- **Mobile First** - Perfect for quick moments on your phone
- **Beautiful Design** - Pink theme for wellness vibes
- **Accessibility** - Easy to read, easy to navigate

## Deploy to Netlify

### Option 1: Deploy from GitHub (Easiest)
1. Go to **https://netlify.com** → Sign in with GitHub
2. Click **"Add new site"** → **"Import existing project"**
3. Select **`tinglott/artisy-store`** repo
4. Base directory: **`apps/momsday`**
5. Build command: **(leave empty)**
6. Publish directory: **`.`**
7. Click **"Deploy"**

### Option 2: Deploy Standalone
1. Download this folder
2. Go to https://netlify.com
3. Drag & drop the folder
4. Done! You'll get a live URL
