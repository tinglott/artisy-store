Four on the public team. All read "in training" — an employee graduates only when the owner reviews the record and signs off, one task type at a time.

  • Aria — Receptionist & Store Guide. Greets visitors, answers product, price, and where-to-buy questions from verified knowledge, and passes anything that matters to the owner with the visitor's own words attached. Graduated — reception only
  • Librarian — Catalog & Books Desk. Goes deep on books, courses, music, and tools — what each includes, how similar titles differ, which fits a stated need.

5. What the command layer does

Designed — not built yet

One day, Aria runs the Command Center over the employees: the owner gives an order in plain words, Aria routes it to the right employee, the employee runs it, and Aria reports back. Read jobs run now; any live job — sending, publishing, booking, paying — runs only if that employee is graduated for that task type. Otherwise it is held, and the owner is told it needs his signature. Money, publishing, and credentials always go to the owner. Nothing is hidden; every run is logged.
