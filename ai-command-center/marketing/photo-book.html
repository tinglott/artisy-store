PhotoBook Maker

A download for AI Command Center buyers — turn your product photos into a PDF book you can send or print.

What it is

A small program that turns a folder of photos into a designed PDF photo book: a cover with your title and first photo, captions under the pictures, page numbers, and a running title in the footer. Pick a layout — one big photo per page, two photos side by side, a grid of three or four, or auto, which mixes full pages and two-photo spreads the way a real book feels. Page size A4, A5, or Letter; portrait or landscape.

What it is good for: a product catalog or portfolio — a baker's cakes, a photographer's samples, a craft seller's lookbook, a realtor's listings. A PDF you can email a customer, attach to a quote, or print. Tested here: it built a 5-page A4 sample book from 6 photos.

Download the files

Five files. Save them all into one folder on your computer.

Download photobook.py Download requirements.txt Download book.yaml Download README.md Download run_example.sh

The example photos are not included — use your own photos. The book.yaml here already points at a folder called my_photos for you to fill. The program is free, open-source software under the MIT claim in its README.

What you need

  1. Python 3 on your computer — free from python.org.
  2. Your own photos in a folder. JPG or PNG. Name them in the order you want them in the book, for example 01_cake.jpg, 02_cake.jpg — the book sorts by filename.
  3. A computer to run it on. It runs on your computer, not in the browser. Use high-resolution photos (at least 2000 px on the long side) for the best printed result.

Set it up

  1. Put the five downloaded files in one folder. Inside that folder, make a folder called my_photos and put your photos in it.
  2. Open a terminal in that folder and run: pip install -r requirements.txt
  3. Simple mode — one command, no config file: python photobook.py -i my_photos -t "My Product Catalog" -o output/my_book.pdf
  4. Config mode — for a book you will rebuild: open book.yaml, set the title and your name, check the photos folder and output path, then run: python photobook.py --config book.yaml You can also write your own captions in book.yaml under custom_captions — one line per photo, by filename.
  5. Open output/my_book.pdf and look through it. If the pages feel sparse, try --layout grid2; for maximum impact, try --layout full.

The README.md in the download is the original project's guide. The steps above match the files here — in the download, the program is photobook.py in the same folder, not in a src/ folder.

What it does not do — read this first

Captions come from filenames or a list you write. There are no AI captions. If a photo is called 01_blueberry_cake.jpg, its caption reads "01 Blueberry Cake" unless you write a better one in book.yaml. Name your photos well.

"Print-ready" overstates it. The book has no bleed support, so for a professional print shop, keep the margins in mind and ask the shop what they need before you print.

In config mode, the --output flag is silently ignored. When you run with --config book.yaml, the output path in book.yaml wins — change it there, not on the command line.

Two extra packages install for no reason. The requirements list click and img2pdf, but the script never uses them. They install harmlessly; you can ignore them.

No back cover. The book ends with the last photo page. The demo runner run_example.sh is the original project's script and expects the original folder layout (a src/ folder and an examples/ folder) — the steps above are the ones that work with the files here.
