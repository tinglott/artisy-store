Email Auto-Responder

A download for AI Command Center buyers — replies drafted for you, while you stay in charge.

What it is

A small program that watches your inbox and drafts replies with a free model, so no customer email sits unanswered. It checks for new mail every 60 seconds. When it finds an unread email, it writes a short, polite draft reply.

Drafts only. By default it only saves drafts to a folder on your computer. It sends nothing. If you want it to send replies on its own, you open the script and change one line yourself (SEND_REPLIES = True) — that choice is yours, and yours alone.

Download the files

Three files. Save them all into one folder on your computer.

Download auto_email_responder.py Download requirements.txt Download .env.example

The program is free, open-source software under the MIT license.

What you need

  1. Python 3 on your computer — free from python.org.
  2. Your own email address and an app password. For Gmail: turn on 2-step verification, then make an app password. Never share that password with anyone.
  3. A free Hugging Face token from huggingface.co/settings/tokens — free, no card.
  4. A computer left running. The program only works while it is running, so it needs a computer that stays on.

Set it up

  1. Put the three downloaded files in one folder.
  2. Open a terminal in that folder and run: pip install -r requirements.txt
  3. Copy .env.example to a new file called .env and fill in your email address, your app password, and your free Hugging Face token.
  4. Run it: python auto_email_responder.py
  5. Check the drafts/ folder it creates. Read each draft before you send it yourself. When you trust it, and only then, you may change SEND_REPLIES to True in the script.

It skips newsletters and no-reply addresses, and it remembers which emails it has already handled so it never replies twice to the same one.

What it does not do — read this first

It needs a computer running all day. If the computer is off, nothing is drafted. There is no hosted version — this is a download you run yourself.

It writes generic replies. It does not know your products, your prices, or your customers, and it has no approval flow. It is not an employee. Do not point it at anything where a wrong reply would cost you — refunds, complaints, and anything that matters still need a person.

A full live reply has not been run yet. The model address was updated to Hugging Face's current address in November 2026, and the program has not yet been tested end to end with a real reply. If you get stuck setting it up, or a reply does not come back, support is available to help fix it — reach out and we will work through it with you.
