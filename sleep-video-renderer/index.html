Quick Start: How to Create the Videos

Option A: Free Online Editor (Easiest)

  1. Download files: Get Part 1 audio + all coloring images (100 images in ZIP)
  2. Open Kapwing: Go to https://www.kapwing.com (free, no login needed for basic editing)
  3. Create video:
    • Click "Create" → "Video editor"
    • Upload Part 1 audio as base layer
    • Add images sequentially (each ~7 seconds)
    • Set duration to match audio length
    • Export as MP4 (1080p)
  4. Repeat for Parts 2 & 3

Option B: Free Desktop Software (Faster)

Use DaVinci Resolve (free forever, professional-grade):

  1. Download: https://www.blackmagicdesign.com/products/davinciresolve
  2. Create new project
  3. Drag audio to timeline
  4. Add coloring images to video track (loop each 7 seconds)
  5. Export: File → Export → MP4 1080p

Option C: CapCut (Mobile-Friendly)

Fastest on phone or desktop:

  1. Download CapCut app (free on App Store, Google Play, or desktop)
  2. New project → portrait or landscape
  3. Add audio file
  4. Add images from your library, set each to 7 seconds
  5. Export as MP4
Pro tip: When looping images, set each to display for ~7 seconds. This creates a slow, meditative pace perfect for sleep content. Don't add effects or transitions — keep it clean and calming.

After You Create the Videos

  1. Upload to YouTube:
    • Go to YouTube Studio (studio.youtube.com)
    • Click "Create" → "Upload video"
    • Drag MP4 file
  2. Fill in metadata:
    • Title: At the Back of the North Wind — Part 1: Beginning
    • Description: Paste from "YouTube Descriptions" tab above
    • Thumbnail: YouTube auto-generates
  3. Publish: Set to "Public" and click "Publish"
⏱️ Time estimate: 2–5 minutes per video in online editor, ~30 min total for all 3 if done back-to-back.
