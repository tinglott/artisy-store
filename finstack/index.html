🔄 Request Flow — Chat to Resolution

1
Customer sends message → Chatwoot WidgetWidget fires webhook to your Express/Node.js backend on every new message
2
RAG Retrieval — Supabase pgvectorEmbed query, cosine-search policy docs, FAQs, and product catalog; top-5 chunks injected as context
3
Memory Load — Mem0Pull session history + persistent user memory (past orders, preferences, prior issues)
4
LangGraph Agent Routes to SpecialistClassifier node routes: ORDER → order-agent, REFUND → refund-agent, PRODUCT → product-agent, GENERAL → base LLM
5
Tool Calls — Shopify MCP / n8nAgent fetches live order status, checks inventory, or triggers n8n refund workflow via webhook
6
Response + HITL CheckIf confidence < 0.7 or refund > $200, pause graph at HITL checkpoint → Chatwoot assigns to human agent
7
Tracing — LangFuse / LangSmithEvery step, token, latency, and tool call logged; RAGAS eval runs post-batch nightly

🤖 Multi-Agent Specialist Roles

  • Order Agent — status, tracking, modifications
  • Refund Agent — eligibility, Stripe mutations
  • Product Agent — search, recommendations, MCP cart
  • Escalation Agent — HITL, ticket creation, routing
  • Proactive Agent — abandonment, sentiment triggers

🛡️ Security & Compliance

  • Supabase RLS on all customer data tables
  • API key rotation via environment variables
  • Rate limiting with express-rate-limit
  • PII scrubbing before LLM calls
  • Audit log table for all agent actions

🌍 Scale & Deployment

  • Docker Compose: Node + Chatwoot + n8n + Ollama
  • Railway / Render / Fly.io for $5-20/mo hosting
  • Supabase free tier → Pro at 10K users
  • 100+ language support via Qwen3 multilingual
  • Horizontal scale: stateless Node workers + Redis

📡 Ingest Pipeline (RAG Setup)

  • Chunk PDFs/HTML via RAGFlow parsing
  • Generate embeddings: text-embedding-3-small
  • Store in Supabase with metadata filters
  • Re-ingest on product/policy update webhook
  • Scheduled nightly coherence checks
