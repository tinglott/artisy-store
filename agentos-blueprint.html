🚀 Deployment Guide


    

      
      

        

          

            1
            
Clone & Setup

          

          
git clone https://github.com/YOUR_USER/tlott-agent-os.git
cd tlott-agent-os
cp .env.example .env
# Edit .env with your tokens (all free tier)

        

      


      
      

        

          

            2
            
Get Free API Keys

          

          

            

              
ServiceURLWhat You Get

              
                
HuggingFacehuggingface.co/settings/tokensFree inference API

                
Supabasesupabase.com/dashboard500MB Postgres + pgvector

                
Groqconsole.groq.com/keysFast LLM fallback

              
            

          

        

      


      
      

        

          

            3
            
Test Locally

          

          
# Install dependencies
pip install -r requirements.txt

# Boot the kernel
python aios_kernel.py

# Start API server
uvicorn main_api:app --reload --port 8000

# Or run the full Gradio UI
python hf_deploy/app.py

        

      


      
      

        

          

            4
            
Deploy to HuggingFace Spaces (Free Forever)

          

          
# Push to HuggingFace
git remote add hf https://huggingface.co/spaces/YOUR_USER/tlott-agent-os
git push hf main

# Add secrets in HF Space settings:
# HF_TOKEN, SUPABASE_URL, SUPABASE_KEY, GROQ_API_KEY

          
HuggingFace Spaces provides free CPU hosting with persistent storage. Your AgentOS runs 24/7 at zero cost.

        

      


      
      

        

          

            5
            
Scale with Multi-Space Architecture

          

          
Duplicate your HF Space for specialized "AI Centers" — one for research, one for content, one for business ops. Each shares the same Supabase memory layer, so agents across centers maintain shared context.
