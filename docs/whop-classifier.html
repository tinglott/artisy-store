How to use:

  1. Get a free Groq API key from console.groq.com
  2. Click "Change API Key" and paste your key
  3. Go to your Whop dashboard → Support Chats
  4. Copy all customer messages you want to classify
  5. Paste them in the "Paste Messages" tab (one per line)
  6. Click "Classify All Messages"
  7. View results or export as CSV
