🔧 Configure Companion

Set up API keys for Ting's Smart Companion. These are stored locally in your browser.

Get one at console.groq.com/keys
Get one at makersuite.google.com/app/apikey
How it works: Your Companion will try Ollama locally first, then fall back to Groq/Gemini if available. If no keys are set, it uses public APIs or knowledge-base fallback.
