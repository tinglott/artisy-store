# 💜 ParentWise - ADHD Support Companion

**Real, working app for parents raising kids with ADHD.**

## What It Does

ParentWise is a fully functional wellness companion app built specifically for parents managing ADHD kids. It includes:

✅ **Daily Routine Tracker** - Visual progress bars, task completion tracking
✅ **Stress Relief Tools** - 4-7-8 Breathing, Progressive Muscle Relaxation, Body Scans, 5-Senses Check (all with step-by-step guides)
✅ **ADHD Education** - Real facts about ADHD symptoms and what parents need to know
✅ **Mood Tracker** - Track YOUR mood and energy levels, log notes, see patterns
✅ **SOS Overwhelm Kit** - Quick 30-second resets, calm-down strategies, affirmations

## Features Built In

- **100% Local Storage** - All data stays on your device (no tracking, no servers)
- **No Sign-Up Required** - Open and use immediately
- **Mobile Responsive** - Works on phone, tablet, desktop
- **Dark-Themed Friendly Design** - Easy on the eyes
- **Accessibility First** - Built for real humans with ADHD

## Deploy to Netlify

### Option 1: Deploy from GitHub (Easiest)
1. Go to **https://netlify.com** → Sign in with GitHub
2. Click **"Add new site"** → **"Import existing project"**
3. Select **`tinglott/artisy-store`** repo
4. Base directory: **`apps/parentwise`**
5. Build command: **(leave empty)**
6. Publish directory: **`.`**
7. Click **"Deploy"**

### Option 2: Deploy Standalone
1. Download this folder
2. Go to https://netlify.com
3. Drag & drop the folder
4. Done! You'll get a live URL
