# ⚡ NEXUS SuperAgent

AI-Powered Business Automation Platform by TLOTT12.

## Features
- 🤖 5 specialized AI agents (Canva, Whop, Social, Content, Analytics)
- 🏪 Direct Whop API integration (97 products)
- 📱 Multi-platform social publishing via Content360
- 🎨 Canva design automation (OAuth ready)
- 🔐 Secure credential-based access
- ⚡ Real-time task execution with activity logs

## Deploy to Vercel
1. Fork this repo
2. Go to [vercel.com](https://vercel.com) → Import
3. Add environment variables from `.env.example`
4. Deploy!

## Access
Default code: `nexus2026`

## Stack
- Next.js 14 + TypeScript
- Tailwind CSS
- NextAuth.js
- Vercel (serverless)
