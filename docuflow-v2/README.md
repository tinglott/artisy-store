# DocuFlow v2 staging reader

This is an isolated, browser-only staging reader. It opens a user-selected PDF locally with the browser's native PDF viewer; it does not upload or persist the file.

## Deliberate boundaries

- No production publication changes
- No authentication, payment, analytics, or protected delivery
- No secrets or external runtime services
- No claim that local UI controls provide security

A verified backend must be added before connecting paid or private files.
